# Costo estimado de generación

El costo estimado de una respuesta se calcula con los tokens de entrada y los tokens de salida, incluidos los de razonamiento cuando el proveedor los informa, y con las tarifas configuradas para el modelo. Es una estimación en USD, no un comprobante de facturación. El uso de embeddings debe medirse por separado si su API entrega los datos necesarios.
